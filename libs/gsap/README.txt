GSAP runtime (official third-party library)

The two JavaScript files are NOT included in this download because this build
environment cannot fetch the official minified distributions.

To install genuine GSAP 3.14.2 + ScrollTrigger on a connected Windows PC:
  1. Run install-gsap.bat once while connected to the internet.
  2. Confirm both files appear here: gsap.min.js and ScrollTrigger.min.js.
  3. Disconnect from the internet and launch run.bat. All GSAP calls then run locally.

If you cannot install the files, all museum chapters and primary animations
still work offline using native browser animations; GSAP-specific scroll
choreography requires the installed library.
